# 固资采购审批表壳

这是固定资产新购**审批表的界面原型**。它不是业务系统，也**不是业务验收**。不能拿这页判定流程通过或失败。

对照规格 `gdzc-bihuan-v0.1.md`，版本 **v0.1**。本壳只做三块：

- §1 表头、明细里已经写清、可直接作验收输入的字段
- §2 主状态在浏览器里的示意流转
- §8 角色能看到什么、能点什么

未连接飞书、金蝶或 Anycross。看板壳没有做。规格里标成「待麦冬确认」的项，页面上以禁用占位显示，并标明「待确认」。

## 本地打开

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址，一般是 <http://localhost:5173>。

## 可以点什么

1. 打开后是一张空白申请。申请日期默认今天，币别默认人民币。
2. 「载入示例数据」会填入虚构的员工和物料，页面上会标明**示例数据**。
3. 用申请人提交后，字段锁定，出现确认说明，状态变为**待上级审批**。
4. 切换「你正在以这个角色查看」：
   - 申请人·生产只看到原料码，看不到完整物料
   - 申请人上级、固资采购员在自己的节点上只读，可以通过或驳回
   - 管理者只看这一张单的进度，没有看板

刷新页面会丢掉当前填写。保存只留在这一页的内存里。

物料显隐是界面演示，不是权限系统。
